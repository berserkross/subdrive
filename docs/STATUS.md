## 共享文件夹的实现边界（D27 定稿后，按默认规则推进，用户可随时推翻）

1. 授权名单可为空：等于「只有创建者能看」，但对象本身仍是共享文件夹，不降级为普通文件夹。
2. 授权成员不能再把文件夹转授给第三人（避免权限扩散，成员名单只有创建者能改）。
3. 目录 `rename` / `move` 必须与授权表在同一事务里同步路径前缀，否则权限静默失配。
4. 删除共享文件夹时，别的成员传进来的文件随之消失，配额回冲给**各自的上传者**（不还给创建者）。
5. 被移出名单的成员，其先前上传的文件仍留在目录里且仍占他的配额；他失去访问权，也失去自删权。
6. Seafile 侧不做真实 ACL：共享的可见性完全由后端归属门 + 数据库授权表决定。
