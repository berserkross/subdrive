# SubDrive 本地生产改造验收

从「设置 → 布局与积木 → 打开全屏编辑器」进入。支持模块和独立贴图自由移动、缩放与撤销。网格吸附默认关闭。旧外观键及主题包字段保持兼容，新包增加可选画布。

| 02 | `static/visual-components.css`，统一控件、表格、抽屉和反馈样式 | `step-02-components` |
