# SubDrive 视觉规范 v1

| 规则 | 规格 |
|---|---|
| 字号 | 11 / 12 / 13 / 14 / 16 / 20 / 26px。正文 14px |
| 行高 | 16 / 20 / 24 / 28 / 32px。正文 20px |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32px |
| 圆角 | 控件 8px，面板 12px，弹层 16px |
| 控件 | 分段与图标按钮 32px，普通按钮 36px，常用输入框 40px |
| 图标 | 常用 16px。图标与文字间距 8px |
| 表格 | 固定列策略，表头与数据使用同一水平内边距。数字使用等宽数字并右对齐 |
| 窄屏文件行 | 复选框、文件内容、操作三列。大小与日期放在名称下方 |
| 焦点 | 2px 主色描边，偏移 2px |
| 动效 | 120ms / 200ms，系统要求减少动效时关闭动画和过渡 |

浅色以暖灰页面衬托白色内容。深色使用独立的背景、面板、边框与文字色阶。系统跟随与四种预设主色共同使用语义变量，自定义主色由用户选择。内置浅色与深色正文最低对比度分别为 12.33:1 和 10.07:1，辅助文字分别为 4.19:1 和 5.06:1。自定义配色与贴图需要根据实际搭配判断可读性。

全屏编辑器通过网盘 DOM 预览，画布坐标按内容区宽度缩放。默认自由定位。启用网格吸附后，拖动与缩放以 8px 为步进，坐标输入仍可用于精确定位。独立贴图位于装饰层，正式页面上的贴图允许点击穿透。内容换行或增加时，下方原本不相交的模块会顺延。用户主动叠放的模块保持叠放。

布局编辑器支持 40 步历史、极简白、深色专注和纸张预设。保存前可复制草稿主题包。恢复默认布局从设置页清除画布。已保存的布局可随主题包导入、导出与组织发布。

实现分布在 `static/visual-tokens.css`、`static/visual-components.css`、`static/visual-pages.css`、`static/canvas-runtime.*` 和全屏编辑器文件。运行时使用本地静态资源和浏览器原生接口。
