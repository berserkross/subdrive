# 本地部署（localhost，用自己的电脑跑）

> 目标：像开发/验收时一样，在这台机器上把 SubDrive 跑起来，浏览器打开 `http://127.0.0.1:8010`。
> 面向：想本机试用、开发、跑测试的人。生产环境请走 [部署-私服.md](部署-私服.md)。

## 0. 前提

- Python **3.11+**（3.12 也可以），自带 `venv`
- 一个空目录用来放数据（下方统一用 `<项目目录>/data`）
- 不需要数据库：首次启动自动建 SQLite
- 不需要 Seafile：本地默认用 `stub` 假存储，功能完整、文件落在本地磁盘

## 1. 取代码

```bash
git clone https://github.com/berserkross/subdrive.git
cd subdrive
```

## 2. 建虚拟环境并装依赖

**Windows（PowerShell / Git Bash）**

```bash
python -m venv .venv
.venv/Scripts/python.exe -m pip install -U pip
.venv/Scripts/python.exe -m pip install -r requirements.txt
```

**macOS / Linux**

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -U pip
.venv/bin/python -m pip install -r requirements.txt
```

## 3. 启动

**Windows**

```bash
DATA_DIR=./data SEAFILE_MODE=stub SUBDRIVE_ADMIN_USERNAME=admin SUBDRIVE_ADMIN_PASSWORD='换成你的密码' \
  .venv/Scripts/python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8010
```

**macOS / Linux**

```bash
DATA_DIR=./data SEAFILE_MODE=stub SUBDRIVE_ADMIN_USERNAME=admin SUBDRIVE_ADMIN_PASSWORD='换成你的密码' \
  .venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8010
```

打开 <http://127.0.0.1:8010>。

> 也可以不传 `SUBDRIVE_ADMIN_*`：**第一个注册的账号**会自动成为管理员；之后注册必须用邀请码（管理后台生成）。

## 4. 常用环境变量

| 变量 | 默认 | 说明 |
|---|---|---|
| `DATA_DIR` | `./data` | 数据根目录（SQLite + 文件）。换目录即可多实例并存 |
| `SEAFILE_MODE` | `stub` | 本地用 `stub`；只有接真实 Seafile 才改 `live` |
| `SUBDRIVE_ADMIN_USERNAME` / `SUBDRIVE_ADMIN_PASSWORD` | 空 | 首次启动初始化管理员 |
| `DEFAULT_QUOTA_BYTES` | 20 GiB | 新用户默认配额 |
| `MAX_FILE_BYTES` | 2 GiB | 单文件上限 |
| `SESSION_TTL_DAYS` | 30 | 登录有效期 |
| `SPEEDTEST_MAX_BYTES` | 50 MiB | 测速允许的最大数据量（前端上限 1 GiB，取两者较小值） |

完整列表见 `app/main.py` 顶部的 `os.environ.get(...)`。

## 5. 验证装好了

```bash
# 27 项冒烟
.venv/Scripts/python.exe tests/test_smoke.py

# 51 项功能（加密夹、测速、预览 Range、管理员提升）
.venv/Scripts/python.exe tests/test_features.py

# 108 项浏览器端到端（需要 Chromium/Chrome；会自己起停服务）
.venv/Scripts/python.exe tests/e2e/test_e2e_browser.py
```

全绿的标准输出：`108 项通过，0 项失败`。

## 6. 改完代码怎么生效

```bash
# 后端改了：重启 uvicorn（上面的命令 Ctrl+C 再跑一次）
# 只改前端静态文件：刷新浏览器即可；若改了 css/js，记得把 index.html 里的 ?v= 数字 +1 以破缓存
```

## 7. 停掉 / 清空

- 停：终端 `Ctrl+C`
- 清空所有数据（**不可恢复**）：停掉后删除 `./data` 目录

## 8. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| `ModuleNotFoundError: fastapi` | 用了系统 python，改用 `.venv/Scripts/python.exe`（或 `.venv/bin/python`） |
| 页面空白 | 浏览器缓存了旧的 `app.js`。硬刷新（Ctrl+Shift+R），或确认 `static/index.html` 里的 `?v=` 已递增 |
| 端口被占用 | 换 `--port 8011`，或先结束占用 8010 的进程 |
| 登录后立刻掉线 | 换了 `DATA_DIR` 或删了 `data/subdrive.db`，会话表没了；重新登录即可 |
